Support

Get help

Ask questions and report bugs in GitHub Issues. Search the existing issues first. When you open a new one, include:

  • your Screen Setter version, from Settings › General › About,
  • your macOS version and Mac model,
  • the displays involved and how they're connected,
  • what you expected and what happened instead.

Support is voluntary and best effort, so there's no guaranteed response time.

Report a security problem

Please don't post security problems in a public issue. Report them privately as described in SECURITY.md.

Common fixes

  • macOS won't open the app the first time. Open System Settings › Privacy & Security, scroll down, click Open Anyway, and confirm with Open.
  • A display went dark after switching. Choose Undo in the menu, unplug and reconnect the display, or fix the arrangement in System Settings › Displays.
  • The menu bar icon is missing. macOS hides menu bar items when there's no room. Open the app again to show its settings.
  • A keyboard shortcut does nothing. Another app may already use it. The menu then shows Review Keyboard Shortcuts… so you can choose another.
  • An automatic layout didn't apply. It only applies when exactly the same displays are connected and the saved resolutions and mirroring are still available. The menu shows Review Display Layout… with the reason.
